# MadNegar v1.0.0 — یادداشت‌های انتشار اولیه

نسخهٔ 1.0.0 نخستین نسخهٔ بسته‌بندی‌شدهٔ MadNegar برای Windows x64 بود. این نسخه قابلیت‌های اصلی رونویسی محلی گفتار، تایپ صوتی و ابزارهای کاربردی متن را در قالب نصب‌کننده و فایل اجرایی مستقل ارائه کرد.

## قابلیت‌های اولیه

- دریافت گفتار از میکروفون و تولید متن نهایی در موتورهای پشتیبانی‌شده.
- تنظیم جداگانهٔ زبان گفتار و ترجیح زبان متن خروجی، با تمهیداتی برای فارسی، انگلیسی و گفتار ترکیبی.
- حفظ برخی اصطلاحات فنی انگلیسی به خط لاتین و امکان استفاده از واژه‌نامهٔ محلی.
- تایپ صوتی با میان‌بر اختیاری و امکان کپی‌کردن متن به‌جای درج خودکار آن.
- خروجی متن و قابلیت‌های تکمیلی وابسته به موتور تشخیص گفتار.

این سند تاریخچهٔ نسخهٔ اولیه را ثبت می‌کند؛ نسخهٔ فعلی و فایل‌های دانلود آن در [صفحهٔ انتشار v1.0.1](https://github.com/MadLandGit/MadNegar/releases/tag/v1.0.1) قرار دارند. این یادداشت‌ها به‌تنهایی تضمینی برای دقت تشخیص گفتار در همهٔ مدل‌ها یا شرایط ضبط نیستند.

برای راه‌اندازی و ساخت کد منبع، [README](../README_FA.md) و [راهنمای ساختار پروژه](PROJECT_STRUCTURE_FA.md) را ببینید.
